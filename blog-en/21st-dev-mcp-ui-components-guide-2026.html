Ever told an AI "give me a fancy button" or "make the scroll feel smoother" — and gotten back something nowhere close to what you pictured?

It's not that the AI isn't capable. It's that describing visuals in words always loses something in translation. This post walks through 21st.dev, a library of over 10,000 ready-made React/Tailwind components — each one paired with a prompt you can hand straight to your AI tool. All pricing below is current as of July 2026, with source links so you can verify everything yourself.

What is 21st.dev?

21st.dev is a community component registry built by 700+ design engineers, currently hosting:

  • 2,000+ marketing blocks (animated heroes, headers, landing sections)
  • 2,100+ UI components (buttons, cards, navigation, etc.)
  • 10,000+ components in total

What sets it apart from a typical component library: every component ships with a copy-paste prompt, not just code. Paste that prompt into Claude Code, Cursor, v0, or Lovable, and the AI rebuilds the component inside your project, matched to your theme.

Finding templates and animation effects

  1. Open 21st.dev
  2. Browse by category or search (buttons, cards, hero sections, animated effects, etc.)
  3. Every component has a live preview so you can see the animation before committing
  4. Found one you like? Click through to the detail page

Finding the prompt

On each component's page, look for the "Copy Prompt" button:

  1. Click to copy the prompt
  2. Paste it into Claude Code, Cursor, v0, or Lovable
  3. The AI rebuilds the component in your project and adapts it to your existing style

You can also install components the traditional way via the shadcn CLI.

Connecting the MCP (for people who code often)

If you regularly work in Cursor, Claude Code, or Windsurf, you can connect 21st.dev as an MCP (Model Context Protocol) server — letting your AI search and generate components directly inside your editor, no browser tab-switching required.

Recommended install (21st CLI):

npx @21st-dev/cli@latest init --client cursor

Manual setup: add this to your editor's MCP config:

{
  "mcpServers": {
    "21st": {
      "url": "https://21st.dev/api/mcp",
      "headers": { "x-api-key": "YOUR_API_KEY" }
    }
  }
}

Get your API key at 21st.dev/mcp.

Note: the older @21st-dev/magic package has been superseded by the new 21st MCP server. If you had an old Magic API key, you'll need to generate a new one.
